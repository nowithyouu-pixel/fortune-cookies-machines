A tiny Python program that writes one original fortune-cookie line for a machine — the slip an AI agent would crack open. The fortune is a single deterministic line: a machine's lucky numbers are the weights it was born with, and strangers have already spent most of them asking the same question twice.

## Run it

```sh
python3 main.py
```
